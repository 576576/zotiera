# 自定义 Planet、身份与节点实例

## 0. 一句话

把「一个节点」拆成「一个实例 = Planet × 身份」：Planet 与身份各自成页、都能有多条，
同一时刻只允许一个实例在线；网络挂在实例上，添加网络时选实例，简易模式下自动用默认实例。

## 1. 为什么必须是「实例」而不是两个独立列表

引擎的三个事实决定了这一点：

| 事实 | 出处 | 后果 |
| --- | --- | --- |
| 一个节点只有一份身份 | `files/identity.secret` / `identity.public` 由核心写（`com_zerotierone_sdk_Node.cpp:407`） | 想换身份就得换数据目录 |
| 一个节点只有一个 planet | 数据源里 `planet` 这个文件只有一份 | 想换根服务器同理 |
| 网络的成员资格写在数据目录里 | `networks.d/<id>.conf` 由核心写 | 换目录 = 换掉整套已加入网络 |

现在这些都写在 `files/` 根目录：`DataStore.java:53` 用 `openFileOutput(name, 0)`，
自定义 planet 靠 `hookPlanetFile()` 把 `planet` 这个名字顶替成全局单文件（`Constants.FILE_CUSTOM_PLANET`）。

所以「支持多个」= **每个组合一份数据目录**，而不是在设置里多存几个路径。

## 2. 模型

| 概念 | 持久化 | 唯一键 | 备注 |
| --- | --- | --- | --- |
| Planet | 表 `planets` + 文件 `files/planets/<worldId>.planet` | worldId（8 字节，取自文件头） | 官方 planet 是内置行，worldId 固定，**别名固定 `zerotier.com`**，无文件 |
| Identity | 表 `identities` | nodeId（10 位 hex） | 别名可改；密钥在实例目录里 |
| 实例 | 不单独建表，由 `(planetId, identityId)` 组合 | 二元组 | 目录 `files/instances/<planetId>-<identityId>/` |
| 网络 | `networks` 加 `planet_id`、`identity_id` 两列 | networkId | 两列决定它属于哪个实例 |

实例目录内容：

```
files/instances/<planetId>-<nodeId>/
├── identity.secret      // 从 identities 里拷一份（引擎只认这个文件名）
├── identity.public
├── planet               // 非官方 planet 时写入；官方时不写，走内置
├── networks.d/          // 引擎写
└── peers.d/             // 引擎写
```

`DataStore` 加一个 `baseDir` 构造参数，其余逻辑不动；`hookPlanetFile()` 保留，只是判断依据从
「全局开关」变成「这个实例有没有 planet 文件」。

## 3. 运行时：切换实例

同一时刻只能有一个节点（UDP 9993/9994 只能绑一次），所以：

```
停节点（node 置空、TUN 拆除）
  → 重建 DataStore(实例目录)
  → new Node() + init(dataStore, …)
  → 重新 join 该实例下的网络
```

- `ZeroTierOneService` 里 `private final DataStore dataStore`（第 96 行）改成按实例创建。
- 切换时给一次前台通知「正在切换节点」，避免看起来卡住。
- 切换后的节点 ID 会变（不同身份）→ 通知栏、概览页、设备页都要重新取 `NodeIDEvent`，不能用缓存。

## 4. 页面

### 4.1 管理 Planet（照 Moon 页抄）

结构与 `MoonsScreen` 一致：`AppTopBar` + 列表 + 右下 FAB。

| 区域 | 内容 |
| --- | --- |
| 列表行 | 别名（主）、`zerotier.com` 或 worldId（次）、来源标签：内置 / 文件 |
| 行菜单 | 重命名别名、删除（内置行不可删） |
| FAB | 「添加 Planet」→ 选文件（同 Moon 的 `OpenDocument` 导入）→ 弹框填别名 → 落库 |
| 文件校验 | 首字节 `0x01`，随后 8 字节为 worldId；同 worldId 已存在则提示「已添加（别名 x）」 |
| 生效 | 提示「切换实例后生效」，与 Moon 的「断开重连」同款说法 |

内置行永远在列表最上面，别名 `zerotier.com`，不可改不可删。

### 4.2 管理身份（同构）

同一套结构，入口在**管理 Planet 上面**（设置页里 Planet 行在前、身份行在上，见 4.3）。

| 区域 | 内容 |
| --- | --- |
| 列表行 | 别名（主）、节点 ID（次，等宽）、「未启用」标记（还没生成密钥） |
| 行菜单 | 重命名、删除（有网络挂在该身份上时禁止，提示先删网络）、导出身份 |
| FAB | 「添加身份」→ 两个选项：**生成新身份** / **从文件导入**（复用 `identity-export` 的 zip） |

「生成新身份」不现场起节点：只建一行 + 空目录，密钥等这个实例第一次启用时由引擎补齐，
列表里先显示「未启用」。这样避免为了生成密钥去起一次 VPN 服务。

### 4.3 设置页

- 新增「简易模式」开关，**默认开**，存在 `PREF_SIMPLE_MODE`。
- 开启时隐藏「管理 Planet」「管理身份」两行；「管理 Moon」保留（它是网络内的东西，与实例无关）。
- 关闭后顺序（网络设置之后的这一组）：

```
管理身份      →
管理 Planet   →
管理 Moon     →
```

### 4.4 概览页：只有同实例的网络能同时开

- 列表平铺所有网络，不按实例分组（分组会打乱现在「一个网络一行」的直觉）。
- 当某个网络处于开启状态时，与它 `(planetId, identityId)` 不同的网络：
  开关置灰不可点，summary 追加一行「需先断开 <别名>」。
- 全部关闭时所有网络都可点；点哪个就把实例切到它所属的组合。
- 设备卡的总开关不变：只表示隧道是否运行。

### 4.5 添加网络

| 模式 | 流程 |
| --- | --- |
| 简易模式 | 现状：输入 16 位网络 ID → 加入默认实例（官方 planet + 默认身份） |
| 非简易模式 | 输入 ID 后多一步「选择实例」：两级选择（Planet → 身份），默认选中当前在线实例 |

网络详情页顶部加一行只读信息：`zerotier.com · 默认身份`，让用户随时知道这条网络属于哪个实例。

## 5. 数据迁移（Room v1 → v2）

- 新表 `planets`、`identities`；`networks` 加 `planet_id`、`identity_id` 两列，默认 0 = 官方 planet / 默认身份。
- 迁移里先插入两行内置数据（`zerotier.com`、把现有 `AppNode.nodeId` 作为默认身份），再把所有网络回填到这一对。
- 现有身份文件不搬：迁移只建目录、把 `files/identity.*` 拷进默认实例目录，原文件保留一份不动（回滚用）。
- 迁移必须有测试：v1 库 + 两条网络 → v2 后仍能列出来、仍能连。

## 6. 步骤（每步可独立验收）

| 步 | 内容 | 验收 |
| --- | --- | --- |
| S1 | Room v2：两张表 + networks 两列 + 迁移 | 旧库升级后网络、身份都在；`notifyChange` 正常 |
| S2 | DataStore 按实例目录；默认实例等价于现在 | 默认实例能连，节点 ID 与升级前一致 |
| S3 | 管理 Planet 页（照 Moon） | 导入两个 planet、重命名、删一个，重启后都在 |
| S4 | 管理身份页 + 生成 / 导入 | 新身份首次启用后节点 ID 与列表一致 |
| S5 | 简易模式开关 + 设置页显隐 | 开关切换后两行出现/消失，重启后保持 |
| S6 | 概览页跨实例禁用 | 开 A 实例的网络后，B 实例的网络置灰且有提示 |
| S7 | 添加网络选实例（非简易） | 加到 B 实例后，网络详情显示 B 的别名 |

顺序上 S1/S2 是地基，先做；S3 与 S4 互不依赖，可并行；S5 只依赖 S3/S4 的入口存在。

## 7. 验收标准

- 迁移：v1 库升级后不丢网络，连接行为与升级前一致。
- 两个 Planet、两个身份、三个网络（分属两个实例）：切换实例后节点 ID 变化，网络列表只允许同实例同时在线。
- 简易模式下看不到 Planet/身份入口，添加网络仍是「输 ID 就能连」。
- 删身份有网络挂着时被拦住，提示可读。
- 两种风格 × 明暗，三个新页面各看一遍。

## 8. 风险

| 风险 | 处理 |
| --- | --- |
| 实例目录与 `files/` 根目录并存，引擎读到旧身份 | 默认实例的目录内容从根目录拷过去后，根目录的 `identity.*` 不再被使用；保留但改名 `identity.bak`，避免误读 |
| 切换实例耗时、看起来像卡死 | 切换期间前台通知 + 界面禁用开关 |
| 用户把「身份」当成可随便换的皮肤 | 添加/切换时写明「不同身份 = 不同节点 ID，已授权的网络要重新授权」 |
| planet 文件被核心覆盖 | 保留 `hookPlanetFile()` 的拦截，实例内有 `planet` 文件时不写 |
| 网络记录与实例不一致（实例被删） | 删实例前先校验 `networks` 是否引用，有则拒绝并提示 |
